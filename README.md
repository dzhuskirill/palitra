# Палитра художника

Игра для художников: узнать краску по названию и название по цвету.

Открывается в браузере, ничего устанавливать не нужно, регистрации нет.

**Играть:** https://dzhuskirill.github.io/palitra/

## Что внутри

Три раунда:

- цвет по названию;
- название по цвету;
- «собери оттенки» одной семьи.

Есть тренировка по каждому раунду и справочник «Все краски» (41 краска).

## Про точность

Цвета (hex) взяты из английской Википедии — списков «List of colors» и статей
о цветах; у каждой краски указан источник. Цвет на экране приблизительный.

Чтобы варианты не путались, в одном задании они отличаются не меньше чем на
ΔE 32 (CIE76), а в раунде «собери оттенки» лишние не берутся из соседних
семей цветов. Это контролируют автоматические проверки при сборке.
